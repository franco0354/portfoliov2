# UI/UX Design Rules

## 1. Design Philosophy
- Always prioritize clean, modern, minimal, and professional UI.
- Avoid unnecessary visual decorations.
- Keep the interface simple, consistent, and easy to understand.
- Prioritize usability and readability over decorative design.
- Every UI element must have a clear purpose.
- Avoid designs that look overly AI-generated or template-like.

## 2. Colors
- Always follow the existing project's color palette.
- Never introduce random colors without a valid reason.
- Do not change the established primary, secondary, and accent colors.
- Maintain consistent colors across all pages and components.
- Use neutral colors for backgrounds, borders, and secondary elements.
- Avoid excessive use of accent colors.
- Ensure sufficient contrast between text and backgrounds.
- Do not use gradients anywhere in the UI unless explicitly requested.

## 3. Shadows and Borders
- Avoid excessive shadows.
- Do not add shadows to every card, button, container, or section.
- Prefer subtle borders over unnecessary shadows.
- Use shadows only when they improve visual hierarchy or indicate elevation.
- Avoid heavy, dark, or overly blurred shadows.
- Keep borders subtle and consistent.

## 4. Layout and Spacing
- Maintain consistent spacing throughout the application.
- Avoid overcrowded layouts.
- Do not add unnecessary padding or margins.
- Use proper alignment and visual hierarchy.
- Keep layouts balanced and organized.
- Avoid unnecessary nested containers.
- Make good use of available screen space.

## 5. Typography
- Use consistent font families and font weights.
- Establish a clear typography hierarchy.
- Avoid using too many font sizes.
- Do not overuse bold text.
- Keep text readable and appropriately sized.
- Avoid unnecessarily large headings.

## 6. Components
- Reuse existing components whenever possible.
- Follow the existing design system.
- Keep buttons, inputs, cards, modals, and dropdowns visually consistent.
- Avoid creating duplicate components.
- Use consistent border radius across similar components.
- Do not add unnecessary icons or decorative elements.
- Keep buttons visually simple and easy to recognize.

## 7. Responsive Design
- Ensure the UI works properly on desktop, tablet, and mobile.
- Avoid fixed widths when they cause responsiveness issues.
- Prevent horizontal overflow.
- Maintain proper spacing on smaller screens.
- Ensure navigation and interactive elements remain accessible.

## 8. User Experience
- Prioritize intuitive navigation.
- Provide clear feedback for loading, success, and error states.
- Avoid unnecessary animations and transitions.
- Keep interactions predictable and consistent.
- Make forms simple and easy to use.
- Never sacrifice usability for visual appearance.

## 9. Existing Design Preservation
- Before modifying UI, inspect the existing design and components.
- Follow the established visual style of the project.
- Do not redesign existing pages unless explicitly requested.
- Do not change the color palette, typography, or spacing system unnecessarily.
- When adding new features, make them look like they belong to the existing application.
- Avoid changing unrelated UI components.

## 10. Before Completing UI Tasks
- Review the entire modified interface.
- Check color consistency.
- Check spacing and alignment.
- Remove unnecessary shadows and decorative elements.
- Verify responsiveness.
- Ensure the final result looks clean, consistent, and professional.

## Golden Rule

Build clean and functional interfaces, not overly decorated ones.

No gradients. No excessive shadows. No random colors. No unnecessary decorations.

Always follow the existing design system unless explicitly instructed otherwise.
